\section{Memory Architecture}
\label{sec:memory_arch}

\subsection{SRAM Subsystem}
\label{subsec:sram_subsystem}
The on-chip SRAM subsystem delivers high-bandwidth vector loads to Helium execution units.
The SRAM hierarchy contains banked memory controllers with independent crossbar routing.

\subsubsection*{Unnumbered Buffer Configuration}
The scratchpad buffer allocation is partitioned statically at compile time.
Buffer addresses are locked into dedicated address registers to prevent TLB misses.

\begin{definition}[Tiled Activation Bank]
A contiguous block of 64KB SRAM allocated strictly for intermediate layer tensor activations during matrix multiply operations.
\end{definition}

Additional trailing remarks on SRAM voltage scaling and retention modes during sleep cycles.

\subsection{Compute Core}
\label{subsec:compute_core}
The compute core executes fused multiply-accumulate operations at 1 MAC per cycle per lane.
Branch prediction uses a 2-bit saturating counter array.
